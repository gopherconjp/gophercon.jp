# CFP 要項

GopherCon Japanは、日本で開催されるGoの"半"国際カンファレンスです。  
Goを使う人、Goに関心を持つ人、Goコミュニティに関わる人が、日本語・英語という言語の境界を越えて集まり、学び、交流する場をつくることを目指しています。

日本のGopherにとっては、海外のGopherやグローバルなGoコミュニティとつながる機会に。  
海外のGopherにとっては、日本を訪れ、日本のGoコミュニティに触れるきっかけに。

このCall for Proposalsでは、Goに関する知見、実践、探求、挑戦を共有してくださるスピーカーを募集します。  
Goの経験年数、登壇経験、母語、所属、バックグラウンドは問いません。世界中の全ての方からの応募を歓迎します。

初めてカンファレンス登壇に挑戦する方、普段とは異なる言語での登壇に挑戦したい方も、ぜひご応募ください。

## 募集するプロポーザル

GopherCon Japanでは、以下の3種類のプロポーザルを募集します。

### 通常セッション

30分のセッションです (質疑応答の時間は含みません)。  
Goに関する技術的な知見、実践事例、設計・運用の経験、Go本体や標準ライブラリの仕組みの深掘りなど、まとまった内容を共有する発表を想定しています。

### チャレンジセッション

20分のセッションです (質疑応答の時間は含みません)。  
チャレンジセッションは、登壇者にとって何らかの「挑戦」を含む発表のための枠です。特に、以下のような方からの応募を歓迎します。

- 初めてカンファレンス登壇に挑戦する方
- 普段使っている言語とは異なる言語で発表してみたい方

GopherCon Japanでは、言語の壁を越えた登壇への挑戦を歓迎します。特に、日本語での登壇経験が豊富な方には、ぜひ英語での登壇に挑戦していただきたいと考えています。

### ショートトーク

5〜7分の短い発表です (質疑応答の時間は含みません)。  
小さな発見、試してみたこと、失敗から得た学び、OSSやツールの紹介、コミュニティ活動の共有など、短時間で参加者に新しい気づきを届ける発表を想定しています。

## プロポーザル提出時に必要な情報

プロポーザルを提出する際は、以下の情報を入力・選択してください。  
文章で回答する項目については、選択した登壇言語 (主に登壇を希望する言語) でご回答ください。

### Session Title (セッションタイトル)

セッションの内容が分かるタイトルを40字以内で入力してください。

### Description (セッション概要)

セッションで扱う内容、対象となる参加者、参加者が得られる知見を400字以内で入力してください。

### 登壇言語

主に登壇を希望する言語を選択してください。

- 日本語
- 英語

### もう一方の言語での登壇可否 (任意)

主に希望する登壇言語とは別の言語でも登壇可能かどうかを選択してください。  
本項目を「可能である」とお答えいただいた場合、時間や発表者枠の都合により、運営からもう一方の言語での発表をお願いする場合がございます

### プロポーザルタイプ

以下のいずれか1つを選択してください。

- 通常セッション
- チャレンジセッション
- ショートトーク

### ターゲット

以下の5つから、応募内容に最も近いターゲットを1つ選択してください。各ターゲットの詳細は、後述の「ターゲットについて」を参照してください。

- Use Case Beginner / 活用事例・初級
- Use Case Intermediate / 活用事例・中級
- Internal Beginner / 仕組みの深掘り・初級
- Internal Intermediate / 仕組みの深掘り・中級
- Advanced / 上級

### アウトライン (任意)

セッションで扱う内容や発表の構成・進行の流れを入力してください。大まかなセクションごとの時間配分もあわせて記入することを推奨します。  
本項目に文字数指定はございません。また、この項目は採択審査の参考としてのみ使用し、公開しません。

### チャレンジセッションに応募する場合の挑戦内容 (任意)

チャレンジセッションに応募する場合は、どのような挑戦を含む発表なのかを入力してください。

例:

- 初めての大規模カンファレンス登壇
- 普段使っている言語とは異なる言語での登壇

## ターゲットについて

GopherCon Japanでは、発表の対象者と内容の方向性を示す分類として、５種類の「**ターゲット**」を設けています。  
これらは、応募者自身が内容を検討する際、および運営による選考段階において「誰に向けた発表なのか」「どのような視点でGoを語るのか」を整理し、採択されるプロポーザルの方向性が偏りすぎることを避けるため設けられました。

ターゲットは、発表内容について**難易度**と**分野**を軸として分類しています。

### 難易度

発表内容の難易度を **Beginner / Intermediate / Advanced** の三段階で捉えます。  
参加者がGoについてどの程度の経験や知識を持つことを想定しているかを表します。

### 分野

発表の内容を**Use Case（活用事例）/ Internal（仕組みの深掘り）** の二軸で捉えます。  
発表内容が、Goを実際に活用するうえでの実践的な知見と、Go本体やその周辺技術の仕組みへの好奇心のどちらに主な焦点を当てているかを表します。

難易度がAdvancedであるものの多くは分野横断的な発表であることが想定されるため、分野による分類を行いません。

---

以下は、各ターゲットについての詳細です。  
応募時には、以下の5つのターゲットのうち最も近いものを選択してください。

### Use Case Beginner / 活用事例・初級

Goの経験が0〜2年程度の方でも楽しめる、Goの活用事例や学び方、開発のコツを扱うセッションです。  
Goを使い始めたばかりの方に向けた実践知、学習の過程で得た気づき、ツールやライブラリの紹介、AIとのカジュアルな連携、OSSやコミュニティ活動への入り口などを想定しています。  
Use Case Beginnerでは、「なぜその人が話すのか」「どのような経験や情熱から生まれた発表なのか」を大切にします。

### Use Case Intermediate / 活用事例・中級

Goを使った開発経験をある程度積んでいる参加者を対象にした、Goの実践的な活用事例や開発・運用の知見を扱うセッションです。  
大規模システムでのGo活用、設計・運用上の判断、パフォーマンスチューニング、可観測性、ツールの深い活用、コードベースの改善、チーム開発での工夫などを想定しています。  
広く知られてはいないものの、他の現場でも応用できる知見や参加者が自身のプロジェクトに持ち帰って実践できる学びを歓迎します。

### Internal Beginner / 仕組みの深掘り・初級

Goの経験が0〜2年程度の方や、コンピュータサイエンスに関する前提知識がない方でも楽しめる、仕組みの深掘りを扱うセッションです。  
Tour of Go程度の知識がある参加者を想定し、前提から丁寧に説明される内容を歓迎します。  
細かな実装の詳細ではなく、「なぜそうなっているのか」「何が嬉しいのか」「何をしてくれるのか」「どのように理解するとよいのか」を伝える発表を想定しています。  
初心者にとっては新しい入り口に、中級者以上にとっては再発見につながるようなセッションを歓迎します。

### Internal Intermediate / 仕組みの深掘り・中級

Goを使った開発経験をある程度積んでおり、コンピュータサイエンスの基礎知識を持つ参加者を対象にした、仕組みの深掘りを扱うセッションです。  
Goランタイム、標準ライブラリ、テスト、並行処理、メモリ管理、ツールチェインなど、普段Gopherが利用している機能の裏側を知る発表を想定しています。  
「どのように実装されているのか」「その設計にはどのような背景があるのか」「その理解が実践にどう活きるのか」を伝える内容を歓迎します。

### Advanced / 上級

Goとコンピュータサイエンスの双方について高い水準の知識を持つ参加者を対象にしたセッションです。  
GoやGoで実装されたソフトウェアの深い内部構造、前例の少ない活用法、高度なツール開発、`ast`、`unsafe`、ABI、コンパイラ、ランタイム、OS、テスト基盤、メタプログラミングなど、Goの奥深い領域を扱う発表を想定しています。  
Advancedでは、Use CaseとInternalを明確に分けません。高度な発表では、Goの内部理解と実践的な応用が密接に結びつくことが多いためです。

## 採択にあたって重視する観点

プロポーザルは、主に以下の観点をもとに検討します。

### Goとの関連性

Go、Goのエコシステム、Goによる開発・運用、Goコミュニティに関係する内容であること。

### 明瞭性

セッションの内容、対象者、持ち帰れる学びが明確であること。

### 正確性

Goに関する正しい知見を、応募者自身の経験や調査に基づいて共有する内容であること。

### 達成可能性

選択したセッション時間内で、無理なく伝えられる内容であること。

### インパクト

参加者が新しいアイデア、技術、ツール、視点、判断材料を得られる内容であること。

### ターゲットとの適合性

対象者像や内容の深さが、選択したターゲットに合っていること。

## 応募上の注意

- プロポーザルは、1人につき2件まで応募できます。ただし、採択されるプロポーザルは1人につき1件までです。
- すべての発表は単独登壇のみとします。複数人での登壇はできません。
- 応募言語は日本語または英語です。
- 登壇言語は日本語または英語です。
- 応募時に、登壇したい言語を選択してください。
- 可能な場合は、もう一方の言語での登壇可否も入力してください。
- プロポーザルの内容は、Goに関連するものにしてください。
- 他言語、他コミュニティ、特定の個人・団体への批判を主目的とする内容はお控えください。
- 過度なプロダクト紹介や宣伝を主目的とする内容はお控えください。
- 当日は、開催の様子を写真や動画で撮影し、広報目的で利用する場合があります。プロポーザルを提出した時点で、これらの撮影および利用に同意いただいたものとします。
- 応募にあたっては、[Go Community Code of Conduct](https://go.dev/conduct) を遵守してください。

## 最後に

GopherCon Japanは、日本のGoコミュニティと世界のGoコミュニティをつなぐ、開かれた場を目指しています。

Goを長く使っている方も、最近Goを学び始めた方も。  
日本語で話したい方も、英語で話したい方も。  
日本から世界に向けて話したい方も、海外から日本のGopherに向けて話したい方も。

あなたの経験、知見、疑問、探求、挑戦を、ぜひGopherCon Japanで共有してください。  
皆さんからのプロポーザルをお待ちしています！
